# ACR 18.7 对齐记录

基线为用户提供的本机 ACR 18.7 界面截图；后续 Adobe 网页的新增功能不自动纳入该基线。日期 2026-10-26，CaptRAW 0.4。定位仍为完整非生成式 ACR 替代及独立可复用显影核心，当前版本是可安装的中间原型，尚未满足完整替代。

“已接入”表示 CaptRAW 有真实处理和本机证据，不表示达到 ACR 的画质、算法、数值或效率。“部分”表示只能完成子集；“缺失”表示产品不能完成；“未验证”不能算支持。没有使用外部闭源程序补齐运行能力。

| 能力 | 当前状态 | 实现、证据或剩余缺口 |
|---|---|---|
| Nikon Bayer NEF、Canon CR3、Fujifilm X-Trans RAF | 已接入，样本有限 | 固定三种真实样本与 ART CLI 同配方输出完全一致；不能推及全部机型与模式 |
| Nikon Z5II HE / HE★ | 已接入，有限样本验证 | 两张公开样本逐感光点匹配固定上游参考，并在安装版核心预览；HE 公开样本 10,688,000 感光点和 HE★ 用户样本 24,498,560 感光点分别与独立 Adobe DNG 参考完全一致；用户图预览和 TIFF 通过 |
| 其他 Nikon HE / HE★ 机型、比例及尺寸 | 部分验证 | 上游清单 29 个 HE / HE★ 样本，本机完成 3 个公开样本（Z5II 的 HE / HE★、Z9 的 HE）；其余下载仍未完成，本机未完成覆盖；`tests/nikon-he.mjs` 固定来源、模式、哈希与上游参考，后续逐文件验收 |
| RAW 默认有效区与相机构图裁切 | 部分 | 用户 Z5II 样本 ART 可用尺寸 6056×4032，截图中的 ACR 为 6048×4032；独立参考 DNG 的 DefaultCropOrigin 为 (8,4)、DefaultCropSize 为 (6048,4032)，ActiveArea 为 6064×4040；尚未统一默认裁切与配方坐标语义，感光点解码一致不表示默认构图和色彩一致 |
| 其他相机、特殊压缩、像素位移及多帧 RAW | 未验证 | 必须按机型、压缩模式和样本逐项登记，LibRaw 名称列表不作通过证据 |
| 曝光、对比、白平衡、自然饱和度、饱和度 | 已接入 | `native/recipe.cc`，GUI 控件与实际图像变化；白平衡色调单位为 ART green 的对数投影 |
| 高光、阴影、白色、黑色 | 部分 | ART ToneEqualizer 五频段映射，像素变化已测；尚无 ACR 对照画质与操作等效性验收 |
| 白平衡原照 / 自动 / 相机预设 / 吸管 | 已接入，有限验收 | 原生 ART 精确通道系数；D850 / X-T4 实际预设与图像变化，5 / 11 / 25 像素窗口，旋转 / 裁切位置及撤销恢复；预设库未覆盖的机型不显示预设。未完成所有机型、光谱和光学校正后的定位验收 |
| 输入配置文件、相机匹配、自动 / 自适应调色 | 缺失或未暴露 | ICC/DCP 数据随包，但没有配置文件选择和完整自动匹配工作流；白平衡自动估计不代替自动调色 |
| RGB 总曲线和 R/G/B 多点曲线 | 已接入 | 2–128 点，自然三次样条；四组曲线各 513 采样与 ART 实际采样差 < 1e-12；真实输出走 ART 曲线 |
| 参数曲线、定点工具、曲线直方图 | 缺失 | 多点曲线不代替这些能力 |
| 八色 HSL 混色器 | 已接入，部分 | ART hue 轴曲线，色相 / 饱和度 / 明亮度有实际像素证据；点颜色、颜色范围及定点取样缺失 |
| 颜色分级、校准、黑白混色 | 缺失 | 当前 RGB 曲线和 HSL 不能替代这些工作流 |
| 去朦胧、晕影、颗粒 | 已接入，部分 | 真实 ART 模块且实际像素改变；细分参数、纹理、清晰度未实现 |
| 锐化与传统明亮度 / 颜色降噪 | 已接入，部分 | USM 与 ART RGB 传统降噪；细分控制和完整质量验收未完成 |
| RAW 域 AI 降噪、超分辨率、增强细节 | 缺失 | 没有模型随包；可修改、再分发且画质达标的模型及 RAW 适配路径仍需验证 |
| 自动镜头配置 | 部分 | Lensfun 自动匹配与畸变 / 晕影 / 色差开关；已测样本像素变化；匹配失败提示、手动配置及去边缺失 |
| 裁切、旋转 | 部分 | 自由矩形、90° 旋转及坐标保持已测；比例锁、任意角、拉直、透视和几何辅助缺失 |
| 手动画笔、擦除、线性、径向 | 已接入，部分 | 羽化、坐标、移动中心 / 端点、单笔撤销、独立保存恢复；旋转与裁切像素回归通过 |
| 蒙版组与组件管理 | 已接入 | 创建、改名、复制、排序、隐藏、删除、组反选；组件添加 / 减去 / 相交；真实覆盖像素与独立进程读回一致 |
| 最终蒙版覆盖率显示 | 已接入，有限验收 | 直接取得 ART 生效的组覆盖率，含添加 / 减去 / 相交、羽化与反选；量化为透明度 PNG；适屏、1:1、平移和模式切换实测。详细区按羽化扩展邻域。全尺寸、全部蒙版组合及性能仍需扩大样本验证 |
| 天空、主体、背景、对象、人物和部位蒙版 | 缺失 | 尚无本地分割模型与手工修正闭环；多人、发丝、遮挡和透明物仍需实测 |
| 颜色 / 亮度 / 深度范围、局部完整调节参数 | 缺失或部分 | 局部仅亮度、对比和饱和度；不等同 ACR 局部工具全集 |
| 修复、仿制、内容识别移除、灰尘检查 | 缺失 | 尚未接入处理和交互，不能用蒙版覆盖替代 |
| 反射消除、深度、镜头模糊与散景 | 缺失 | 本地开源处理 / 模型、权重许可及质量路径仍未证实；生成式移除不在本项目范围 |
| HDR 合并、全景、HDR 全景 | 缺失 | 无对齐 / 去鬼影 / 投影 / 合并工作流 |
| HDR 编辑、真实屏幕显示、SDR 预览、HDR 输出 | 缺失 | 当前屏幕和输出限定 sRGB SDR；高位深 TIFF 不表示 HDR 显示通过 |
| 多图会话、撤销重做、初始状态对比 | 已接入，部分 | 真实 GUI、重启恢复和故障恢复通过；无参考图 / 多种前后比较布局 |
| 文件关闭 / 放弃 / 取消、保存后关闭、退出保护 | 已接入 | 文件名、胶片和底栏入口；系统对话框分支自动化验证；退出可返回编辑或放弃退出 |
| 批量同步、批量导出、评分 / 筛选、预设管理 | 缺失 | 当前多图会话不等于图库或批处理；完整图库另属后续产品 |
| 无损保存、处理版本 | 已接入，部分 | 完整 ART 参数与 CaptRAW 组扩展，版本化 JSON 原子保存；支持首版配方；未知引擎拒绝恢复 |
| ACR XMP、预设、配置文件及调整导入 | 缺失 | 现有 XMP/ARP 保持原样；尚无识别 / 转换 / 损失报告，不宣称调整迁移兼容 |
| sRGB JPEG、ICC 16 位 TIFF | 已接入 | 桌面 / 无界面同配方逐像素一致；独立进程、取消与临时输出保护已测 |
| DNG、AVIF、JPEG XL、多色域、输出尺寸 / 锐化 / 水印 | 缺失 | 不能用现有 TIFF 导出代替 |
| 元数据读取 / 保留 / 编辑 / 导出策略 | 部分 | EXIF 相机与曝光信息可见，源文件不改；完整 IPTC / XMP / GPS / 版权、隐私与输出策略未验收 |
| ACR 布局和快捷键 | 部分 | 右工具轨、直方图、折叠调节、底部胶片及完成 / 关闭；E/K/G/J/C/H/R/L/Y 等对齐官方语义；未完成全部快捷键、焦点、缩放和操作耗时对照 |
| macOS / Windows / Linux 产品质量 | 部分 | 当前 macOS 26+ ARM64；其余平台和硬件、签名公证、无障碍、长期稳定性未完成 |
| 核心独立复用 | 已接入，边界有限 | C++ 库与 JSONL 进程无显示服务即可读取、预览、蒙版、处理、输出；仍有 ART CLI 的 GLib / GTK 链接依赖 |

接续次序：先完成已有功能的交互和色彩语义验证、公开 HE 模式样本、配置文件与基础缺口；再补局部完整参数和修复、预设 / Adobe 资产迁移、批处理；三平台、HDR、合并与非生成式 AI 分别设独立验收门槛。AI 的模型权重、转换产物、训练来源与再分发限制须独立列证，不能据“代码开源”推断模型可用。

尚无画质盲评、ACR 对照耗时和全部关键缺口的可信实现证明，因此完整同级替代可行性仍未证实。不会因版本迭代增加控件而降低目标或宣布完成。

依据：用户本机固定版本截图、`native/recipe.cc`、`native/patch-art.mjs`、`apps/desktop/src/`、`tests/` 和本机 `artifacts/`；上游代码为 [ART 固定版本](https://github.com/artraweditor/ART/tree/1e0e12c62e4f329d30bb5624d62a23a663ffbe6b) 与 [LibRaw 解码分支固定版本](https://github.com/pdcgomes/redlamp-libraw/tree/3b20539d3faa766a370e93a529a3b87edffbf0f6)。交互参考 [Adobe 蒙版说明](https://helpx.adobe.com/camera-raw/desktop/edit-and-enhance-images/masking-and-local-adjustments/masking.html) 和 [Adobe 快捷键](https://helpx.adobe.com/camera-raw/desktop/get-started/overview-and-setup/default-keyboard-shortcuts.html)，网页后续更新不改变固定验收基线。
