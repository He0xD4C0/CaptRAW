# 画笔流量、密度与传统 Auto Mask：取证设计

状态：仅设计；未修改生产契约、处理或 XMP 映射。固定基线为本机 ACR 18.7（2743）。

## 已有证据与缺口

- `artifacts/stage-0/acr-reference/ui/09-brush-panel.png`、`09-brush.txt`：大小 3、羽化 63、流动 100、浓度 100、传统自动蒙版入口。只有入口及满值证据，没有低值叠加结论。
- `cases/fuji-xt4-brush-exposure-half.xmp`：真实 18.7 的 `Mask/Paint` 下有 `Flow="1"`、`MaskValue="1"`、`CenterWeight="0.090508"`，Dabs 有 `h` 和 `d` 指令。只有这个样本不能推出低值、擦除、笔压或 Auto Mask 的结构。
- [Adobe 文档](https://helpx.adobe.com/camera-raw/desktop/edit-and-enhance-images/masking-and-local-adjustments/masking.html)将 Flow 定义为应用速率、Density 定义为笔画透明程度、Auto Mask 定义为约束到相似颜色。文档不提供固定 18.7 的累积公式、容差或序列化结构。
- 当前 `Point` 仅含坐标、半径、擦除。`useMaskGesture.ts` 会重采样并把多笔追加到同一 `points`；笔画边界和每笔设置未进入文档。
- `native/recipe.cc` 将所有 ART `DrawnMask::Stroke.opacity` 写为 1。ART `masks.cc` 实际将该值解释为笔尖强度／hardness，并使用标记抑制重复覆盖；不能直接把它接成 Adobe Flow 或 Density。
- 当前 XMP 读取只消费 `r` / `d`，遇到 `h` 等未知 Dabs 指令拒绝整组并保留原结构。不得为了通过导入而丢弃它们，也不得仅添加同名字段后声称等效。

## 固定样本与操作

仅使用项目临时副本。准备一组线性 DNG 均匀灰／灰阶／等亮异色块，以及强边界、低对比边界、断开的同色岛、细线纹理图。真实 RAW 只作独立复核，不用自然场景代替受控样本。

每个案例固定：源文件与校验值、处理版本、配置／白平衡、缩放、尺寸、局部调整、画笔大小／羽化、笔画起终点和工具模式。初始局部曝光使用可见 UI 值；记录实际 XMP，不把 UI 曝光直接当作 XMP 数值。

CUA 的 `drag(from,to)` 没有速度／采样频率参数。记录实际调用时刻和保存后的 Dabs 坐标、数量、间距；不能假称输入速度或点序列相同。重复路径先检验实际几何可比性。

每个案例保存 AX＋截图、实际 XMP、16 位带 ICC 的 TIFF。先导出无蒙版和满覆盖对照，再进行低值实验。所有图像操作通过原生界面；CLI 只做文件校验、像素分析和临时文件管理。

## 低值叠加矩阵

| 变量 | 固定值／变化 | 要区分的问题 |
| --- | --- | --- |
| Flow | 5、20、100；Density 100；羽化 0 | 同一笔往返与抬笔重画是否分别累积；点数／速度的影响 |
| Density | 25、100；Flow 100；羽化 0 | 单笔透明程度、同笔重叠、跨笔叠加是否受相同上限约束 |
| 联合低值 | Flow 20、Density 25 | 稳态上限、累积速率及二者作用顺序 |
| 笔画次数 | 同路径独立落笔 1、2、8 次；另设不抬笔往返 | 不能把“一笔”和“一串采样点”当成同一个语义 |
| 擦除 | 从固定满覆盖开始，同样的低值与次数 | 擦除的 Flow、Density、羽化及边界语义是否与添加相同 |
| 羽化 | 核心案例补 63 | 中心与边缘的累积是否一致；实际 `h` / CenterWeight 变化 |
| 设置归属 | 画完第一笔，再改 Flow／Density，画第二笔 | 旧笔是否保持原设置；参数属于每笔、组件还是整个蒙版 |

先完成上述辨识，不预选 `min(density, old+flow)` 或 `1-(1-flow)^n`。两者只是待排除的假设，不进入生产实现。

## 传统 Auto Mask 稳定参考

1. 同路径、Flow／Density 100、同一笔尖，分别关闭／开启 Auto Mask；跨越等亮异色边界和灰阶边界。
2. 分别从边界两侧起笔，再比较断开的同色岛：区分首点种子、逐点取样和连通性约束，不假设 Adobe 使用哪种方法。
3. 对低对比边界、细线与复杂纹理重复两次；先比较实际 Dabs，再比较 TIFF 响应、边缘泄漏和缺失区域。
4. 保存重开、切换适屏／1:1、对原片做几何变化，检查旧覆盖是否稳定；白平衡／曝光变化单列，判断覆盖是持久结果还是重新计算。
5. 若生成缓存／外部蒙版资产，登记身份、位置、来源、校验值和重开要求；不得仅保存 `autoMask=true` 便认为能复现。

TIFF 输出的色调响应不是蒙版覆盖率。没有独立覆盖证据时只报告实际像素变化、边缘泄漏和稳定性，不反推出精确 alpha，也不使用彩色覆盖层代替输出验收。

## 实现边界提案（等待取证）

- 将一笔的 ID、顺序、添加／擦除、坐标参考和笔尖参数作为不可变文档状态；调整当前画笔设置不重解释旧笔。具体结构在辨明 ACR 设置归属后确定。
- 继承现有坐标服务、revision、单笔事务、Esc 撤回和预览取消；重采样必须在核心以固定图像尺度完成，避免 Web 事件频率改变像素。
- 先评估扩展 ART DrawnMask 的每笔累积能力；需要独立覆盖求解时仍由本地核心完成。前端只显示临时轨迹与覆盖。
- Auto Mask 先比较 ART 已有颜色／边缘原语和可复现的传统方法。种子、阈值、特征来源及缓存身份明确后才选择算法；不能用 AI 或云端补齐。
- 标准 Adobe XMP 只接实测字段和指令，未知属性／限定符保留；尚不支持的整组明确提示。必要的 ART 状态仍在现有版本化 XMP 编辑文档内，不恢复 JSON 编辑文件。
- 默认旧画笔路径保持现有像素；Flow／Density 新路径要有可追踪处理版本，不能静默改写旧笔。

Adobe 语义与画质验收的门槛：拿到低 Flow、低 Density、联合低值、独立重复笔画、擦除、Auto Mask 开关及重开的真实 18.7 样本，明确 XMP 层级和 Dabs 指令，保留未决项。已批准范围内可先实现显式版本化的本地候选管线，验证真实笔画、稳定覆盖、历史和资产生命周期；候选参数不能冒充已证明的 Adobe 指令映射，未完成这些参考前不能宣布 ACR 对齐通过。
